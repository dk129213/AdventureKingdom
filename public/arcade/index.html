    02 The games

    AKARCADE ORIGINAL · MAZE CHASE

    Glitch Run

    Steer Bitsy the bot through a neon maze, hoover up every data bit and dodge four glitches, each with its own way of hunting you. Grab an antivirus chip and the hunters become the hunted.

    • Joystick steer
    • Start pause

    AKARCADE ORIGINAL · CLIMBER

    Rivet Rush

    Clank the crane-bot has gone haywire and is hurling gears down the tower. Climb the ladders, jump the gears and reach the off switch before your bonus runs out.

    • Joystick walk / climb
    • A jump
    • Start pause

    AKARCADE ORIGINAL · PLATFORMER

    Star Hopper

    Guide Pip across three zones: stomp gloops, dodge spikers and flutters, ride moving platforms, grab a shield and take down King Gloop to save the stars.

    • Joystick move
    • A / Up jump
    • B run
    • Start pause

    REAL NES GAME · PUZZLE

    Concentration Room

    A classic memory game running on a real NES emulator: flip two cards, find the matching emblems and clear the table. Story mode, Solitaire, or play the CPU.

    • Joystick move
    • A flip a card
    • Start confirm
